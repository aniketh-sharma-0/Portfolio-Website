# Sketchizel — 3D Artist & Illustrator Portfolio

Official portfolio website for **Sketchizel** (Aniketh) — Multidisciplinary 3D artist, illustrator, and creative aiming for the animation industry.

Built with **React** and **Vite**, featuring a high-impact editorial cadmium yellow hero with interactive kinetic typography, a visual-first artwork showcase directing to ArtStation, and custom discipline curation banners.

---

## 🎨 Featured Works

- **FishBones — Arcane Fan Art**: Jinx's iconic rocket launcher modeled in Blender, hand-painted with Ucupaint textures.
- **Stylized Village Environment**: Modular medieval village environment modeled from scratch in Blender.
- **Rocky Plateau, Cave & Bizo Cat**: Cinematic environment with original rigged feline character and custom controls.
- **Claptrap — Borderlands Fan Art**: Comic-book cel-shaded 3D recreation of CL4P-TP using Blender Grease Pencil and procedural nodes.
- **Snowy Town — Low-Poly Winter Environment**: Storybook winter diorama featuring lantern-lit cottages and warm window glows.
- **Stylized Subway**: Atmospheric neon volumetric interior exploring cyberpunk-inspired lighting.

## ⚡ Tech Stack

- **Framework**: [React 18](https://react.dev/)
- **Bundler / Dev Server**: [Vite 6](https://vitejs.dev/)
- **Styling**: Modern CSS3 (CSS Variables, Flexbox, CSS Grid, hardware-accelerated animations)
- **Typography**: Bebas Neue, Caveat, DM Sans

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed (v18 or higher recommended).

### Installation

```bash
# Clone the repository
git clone https://github.com/aniketh-sharma-0/Portfolio-Website.git

# Navigate into project directory
cd Portfolio-Website

# Install dependencies
npm install

# Start development server
npm run dev
```

The site will be live at `http://localhost:5173/`.

### Production Build

```bash
# Build optimized production bundle
npm run build

# Preview production build locally
npm run preview
```
